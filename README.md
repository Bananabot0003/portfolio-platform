
# Personal Project Showcase App

## Project Description

This is a simple portfolio application I built using React and Vite. It allows users to view projects, add new projects, and search through existing projects.

The purpose of this project was to practice React components, props, state management, and event handling.

## Features

- Displays a list of projects
- Allows users to add projects using a form
- Searches projects by title
- Displays more details about individual projects
- Responsive layout for desktop and mobile

## Setup Instructions

1. Clone the GitHub repository.
2. Open the project folder in VS Code.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the application.
5. Open the local address shown in the terminal.

## Running Tests

Run `npm test` in the terminal.

The tests check the page title, starting projects, adding projects, and searching.

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- React Router
- Vitest
- React Testing Library

## Known Limitations

Projects are stored using React state, so any newly added projects will disappear when the page is refreshed.

The application currently uses sample projects instead of retrieving information from an external API.

## Future Improvements

In the future, I would like to save projects using a database and allow users to upload project images.
